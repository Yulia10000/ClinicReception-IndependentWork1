# Контрольний список перевірки коду

Перед прийняттям змін у проєкті ClinicReception потрібно перевірити:

- [ ] Назви класів і методів відповідають стандарту.
- [ ] Приватні поля починаються з підкреслення.
- [ ] Для відступів використовуються чотири пробіли.
- [ ] Фігурні дужки розташовані з нового рядка.
- [ ] Умовні конструкції мають фігурні дужки.
- [ ] Немає зайвих директив using.
- [ ] Змінні мають зрозумілі назви.
- [ ] Методи виконують одну основну задачу.
- [ ] Вхідні аргументи перевіряються на null, де це необхідно.
- [ ] Дати та часові інтервали запису перевіряються коректно.
- [ ] Код не містить зайвих коментарів і закоментованих фрагментів.
- [ ] Проєкт успішно проходить перевірку dotnet format.
- [ ] Проєкт успішно збирається без попереджень і помилок.
