# Самостійна робота №1
## Стандарт кодування та довідник конструктивних практик команди

**Проєкт:** ClinicReception  
**Мова програмування:** C#  
**Тема:** Запис пацієнтів на прийом до лікаря  
**Варіант:** 4

## Мета роботи

Розробити стандарт кодування для команди розробників, визначити правила написання та оформлення коду C#, налаштувати автоматичну перевірку дотримання цих правил і створити перелік рекомендацій для перевірки програмного коду.

## Структура репозиторію

- `CODING_STANDARD.md` — текстовий стандарт кодування.
- `.editorconfig` — правила форматування та оформлення коду.
- `Directory.Build.props` — загальні налаштування проєктів і аналізаторів.
- `REVIEW_CHECKLIST.md` — перелік перевірок під час аналізу коду.
- `DECISIONS.md` — журнал рішень команди.
- `docs/` — додаткова документація.

## Основні вимоги

Стандарт визначає правила іменування, форматування, коментування, роботи з типами даних, умовними конструкціями та методами. Окрему увагу приділено роботі з датами й часовими інтервалами запису пацієнтів на прийом.
